# Sharpnr Organization Setup Wizard
## Version 1

The **Sharpnr Organization Setup Wizard** guides users through the initial configuration of an organization within the Sharpnr platform.

This wizard is designed to be **step-based**, **modular**, and **extensible**, allowing future enhancements without breaking the setup flow.

---

## Setup Flow

### Step 1: Organization Setup
Configure core organization details such as:
- Organization name
- Contact information
- Basic preferences

---

### Step 2: Property Setup
Define and configure properties under the organization, including:
- Property name
- Location details
- Property type

---

### Step 3: Property Domain & Module Selection
Select applicable domains and modules for each property, for example:
- Hospitality
- Healthcare
- Retail

---

### Step 4: Module Configuration
Configure selected modules based on business needs, such as:
- Feature toggles
- Operational settings
- Default workflows

---

### Step 5: Add Legal Entity
Set up legal and compliance-related information, including:
- Legal entity name
- Tax details
- Registration information

---

### Step 6: Linked Modules & Integrations
Link modules together and enable integrations, including:
- Inter-module dependencies
- External system integrations (if applicable)

---

## Notes
- The setup wizard is **versioned** to allow backward compatibility.
- Each step can be extended independently in future versions.
- Progress can be saved and resumed at any step.
