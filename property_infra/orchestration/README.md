## Property Infra Orchestration

### This is Orchestration Layer for the [**_Property Infra_**](/property_infra)

- We created this orchestration layer so we can centralizes the operation of the infra,
- A hospitality module can use the parking Infra , but hospitality also gonna need the parking infra,
- might be valet parking,
- a Hotel and Restaurant might use the same reception or frontdesk
- so thats why we created this orchestration layer
- we Also have the security desk and many more
